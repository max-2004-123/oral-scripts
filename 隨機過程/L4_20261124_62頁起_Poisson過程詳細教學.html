第 62 頁 · Sampling a Poisson process

每個時間的分類機率不同，怎麼算人數？

先想咖啡店：客人以固定速率 λ 到達。早上客人比較常外帶，晚上比較常內用。因此「客人是外帶」的機率會隨到達時間改變。

令 pᵢ(u) 是時間 u 到達的事件被分成第 i 類的機率；每次依各自到達時間獨立分類，分類也不會互相影響；各類機率加起來是 1。Nᵢ(t) 表示 0 到 t 的第 i 類人數。

Nᵢ(t) ∼ Poisson(mᵢ) mᵢ = E[Nᵢ(t)] = λ∫₀ᵗ pᵢ(u) du。

不同類別的 Nᵢ(t) 互相獨立。這不是只說平均數；它告訴你整個分配。若要求第 i 類恰好 k 次，接著套 Poisson 公式：

P(Nᵢ(t)=k) = e^(−mᵢ) · mᵢ^k / k!。

為什麼要積分？

把時間分成很短的段 Δu。在時間 u 附近，全部事件的平均數約 λΔu；其中第 i 類占 pᵢ(u)，所以這小段的第 i 類平均約 λpᵢ(u)Δu。把所有小段的平均加起來，就得到積分。

每小段的第 i 類平均 ≈ λ × pᵢ(u) × Δu 整段的第 i 類平均 = ∫₀ᵗ λpᵢ(u) du。
補充例：用具體數字代一次。

客人速率 λ=10 人／小時，觀察 2 小時。第一小時外帶機率 0.2，第二小時為 0.6。

E[外帶] = 10×0.2×1 + 10×0.6×1 = 8 人 E[內用] = 10×0.8×1 + 10×0.4×1 = 12 人。

因此外帶數 ∼ Poisson(8)，內用數 ∼ Poisson(12)，且兩者獨立；平均加起來 20 人，正好等於原本 λt=10×2。

不要把每段比例直接相加：0.2+0.6=0.8 不是外帶的平均人數。要先乘每小時平均來幾人，再把各段加起來。也不要把 pᵢ(t) 當成所有時間都固定的機率。

第 63–64 頁 · Proposition 5.3 的證明

為什麼分類後還是獨立 Poisson？

這段投影片公式比較密，我們只看兩類 A、B；更多類是同樣做法。關鍵有三步：已知總數 → 分類 → 把總數條件拿掉。

步驟一：先固定整段有 n 次

已知 N(t)=n，忽略順序來看，n 次事件的到達時間相當於 n 個 Uniform(0,t) 的時間點。事件落在各時刻的機率一樣，所以任意一個事件屬於 A 的平均機率為：

q = (1/t)∫₀ᵗ p_A(u) du。

這個 q 是固定時間長度 t 內、隨機挑一個事件的平均分類機率；不等於每個瞬間的 p_A(u)。t>0。

步驟二：已知總數，就像丟硬幣 n 次

由到達時間與獨立標記的假設，N_A(t)|N(t)=n ∼ Bin(n,q)。如果 A 有 a 個、B 有 b 個，則總數必定 n=a+b：

P(A=a,B=b | N=a+b) = (a+b)!/(a!b!) · q^a(1−q)^b。

步驟三：乘回總數的 Poisson 機率

原過程的 N(t)∼Poisson(λt)，所以：

P(A=a,B=b) = [(a+b)!/(a!b!)]q^a(1−q)^b × [e^(−λt)(λt)^(a+b)/(a+b)!] = [e^(−λtq)(λtq)^a/a!] × [e^(−λt(1−q))(λt(1−q))^b/b!]。

最後一行拆成兩個 Poisson 機率的乘積，所以 A 和 B 在固定 t 的數量獨立；它們的平均分別是 λtq=λ∫p_A 和 λt(1−q)。對互不重疊的時間段也套用同樣的分流及原過程的獨立增量，可得到各分類過程的獨立增量。

容易混淆：

已知總人數固定是 n 時，A 多一個、B 就少一個，因此兩類條件下不獨立。沒有固定總數時，Poisson 隨機總數與分類組合後，兩類卻獨立。

第 65–67 頁 · Infinite-server queue

無限櫃員：現在有多少人還在服務？

模型假設：客人以速率 λ 的 Poisson 過程到達；櫃員無限多，每個人一到就開始服務，沒有排隊；服務時間彼此獨立、同分配，且獨立於到達過程；時間 0 系統為空。

令 V 是一人的服務時間，G(v)=P(V≤v)，Q(v)=1−G(v)。在時間 t：

  • X(t)：0 到 t 到達、且 t 前已完成服務的人數。
  • Y(t)：0 到 t 到達、在 t 還在接受服務的人數。

圖解可左右滑動

同一個客人，先看他有多少時間服務

若客人在 u 到達，現在是 t，他已經有 t−u 的時間服務。所以他在 t 前完成的機率是 G(t−u)；他還沒完成的機率是 Q(t−u)。這些機率會隨到達時間 u 變，所以正好使用上一節的時間相依分流。

E[X(t)] = λ∫₀ᵗ G(t−u)du = λ∫₀ᵗG(v)dv E[Y(t)] = λ∫₀ᵗ Q(t−u)du = λ∫₀ᵗQ(v)dv。

右邊把 v=t−u 代換：u 從 0 增加到 t 時，v 從 t 減到 0，連同負號翻轉積分上下限。兩類人數各自是 Poisson，而且彼此獨立：

X(t) ∼ Poisson(λ∫₀ᵗG(v)dv) Y(t) ∼ Poisson(λ∫₀ᵗQ(v)dv)。

檢查方法：G(v)+Q(v)=1，所以兩個平均相加是 λ∫₀ᵗ1dv=λt，也就是這段時間的平均總到達人數。

補充例：服務平均半小時。

λ=4 人／小時，服務 V∼Exp(2／小時)，觀察 t=1 小時。Q(v)=e^(−2v)，G(v)=1−e^(−2v)。

E[Y(1)] = 4∫₀¹ e^(−2v)dv = 2(1−e^(−2)) ≈ 1.729 人 E[X(1)] = 4 − 1.729 ≈ 2.271 人。

因此 Y(1) ∼ Poisson(1.729…)；「1.729」是平均，不是說實際有 1.729 個人。

別把「總到達人數」和「正在服務人數」混在一起。

已完成的人不在 Y(t) 裡；而若題目一開始已有顧客，還要另外處理這些初始顧客，不能直接套空系統公式。

長期時為什麼 E[Y(t)] 趨近 λE[V]？

非負服務時間滿足 E[V]=∫₀∞P(V>v)dv=∫₀∞Q(v)dv。若 E[V] 有限，時間 t 越大，λ∫₀ᵗQ(v)dv 越接近 λE[V]。這是空系統從 0 啟動後的長期極限。

第 68–71 頁 · 兩個時間點

現在和稍後的服務人數，為什麼會相關？

比較 Y(t) 和 Y(t+s)。有些顧客兩個時間點都在；正是這批共同顧客，使兩個人數有關係。

類型在 t？在 t+s？代表什麼
A在不在t 之前到達，期間完成
B在在兩個時間點都在服務
C不在在t 之後到達，t+s 還沒完成
Y(t)=A+B，Y(t+s)=B+C。

依服務時間及到達時間把人獨立分類，A、B、C 的人數互相獨立且各自 Poisson。注意 Y(t) 與 Y(t+s) 不是獨立，因為都包含 B。

新版第 68–69 頁：三類的機率怎麼寫？

令 y 是顧客的到達時間、V 是他的服務時間，則完成時間為 y+V。以下以 Q(v)=P(V>v)=1−G(v) 表示尾機率。

對 A 類，他先在 t 之前到達，且在 t 到 t+s 之間完成。把完成時間不等式每一項都減去 y：

y < t，且 t < y+V ≤ t+s ⇔ t−y < V ≤ t+s−y p_A(y)=G(t+s−y)−G(t−y)。

對 B 類，他在 t 前到達且一直服務到 t+s，因此 V>t+s−y；對 C 類，他在 t 到 t+s 之間到達，且在 t+s 還沒完成。

p_B(y)=Q(t+s−y)，0≤y≤t p_C(y)=Q(t+s−y)，t<y≤t+s p_A(y)=G(t+s−y)−G(t−y)，0≤y≤t。

每一類在不符合其到達時間範圍時，機率為 0。把 p_A、p_B、p_C 分別乘 λ 對 0 到 t+s 積分，就得到三類 Poisson 人數的平均。它們與投影片的 Type I、II、III 分別對應。

共同的 B 導致共變異數

Cov(Y(t),Y(t+s))=Cov(A+B,B+C) =Cov(A,B)+Cov(A,C)+Var(B)+Cov(B,C) =Var(B)=E[B]。

不相同類別的項因獨立而為 0，最後一步因 B 是 Poisson，變異數等於平均數。B 是 u≤t 到達、服務時間大於 t+s−u 的人：

E[B] = λ∫₀ᵗ Q(t+s−u)du Cov(Y(t),Y(t+s)) = λ∫₀ᵗQ(v+s)dv。

間隔 s 越大，一個人同時留到兩個時間點通常越不容易，因此共同部分通常變少。

如果題目要兩個時間點的聯合機率？

令 A、B、C 各自的 Poisson 平均為 a、b、c。假設 B=ℓ，則 Y(t)=i 需要 A=i−ℓ，Y(t+s)=j 需要 C=j−ℓ。ℓ 不可能大於 i 或 j，因此：

P(Y(t)=i,Y(t+s)=j) = Σ_{ℓ=0}^{min(i,j)} P(B=ℓ)P(A=i−ℓ)P(C=j−ℓ)。

對每個可能的共同人數 ℓ 分類，再加起來。每一項拆成乘積是因 A、B、C 獨立。

第 72–74 頁 · 延遲觀察例題

事件發生了，卻還沒有被觀察到

投影片用 HIV 及症狀延遲作歷史教學模型：感染以未知固定速率 λ 發生，從感染到出現症狀的延遲 V 有已知 CDF G，各人延遲獨立，模型從時間 0 開始。這是簡化的數學示範，不能直接用作現實公共衛生估計。

把「感染」想成客人到達，「出現症狀」想成服務完成：時間 t 時，分成已出現症狀 N₁(t)、尚未出現症狀 N₂(t)。

E[N₁(t)] = λ∫₀ᵗG(v)dv E[N₂(t)] = λ∫₀ᵗQ(v)dv，Q(v)=1−G(v)。

只有已觀察人數，如何估計尚未觀察的？

觀察到已出現症狀 n₁ 人，先以觀察值近似其期望，解出速率估計值 λ̂；再代到尚未出現症狀的期望：

n₁ ≈ λ∫₀ᵗG(v)dv λ̂ = n₁ / ∫₀ᵗG(v)dv 預估未出現症狀人數 = n₁ [∫₀ᵗQ(v)dv]/[∫₀ᵗG(v)dv]。

分母要大於 0。這是用資料與模型得到的估計，不是實際隱藏人數的確定值。

原題的指數延遲例子

若延遲平均 μ 年，Q(v)=e^(−v/μ)，G(v)=1−e^(−v/μ)。先分別求積分：

∫₀ᵗQ(v)dv = μ(1−e^(−t/μ)) ∫₀ᵗG(v)dv = t−μ(1−e^(−t/μ)) 估計 = n₁ μ(1−e^(−t/μ)) / [t−μ(1−e^(−t/μ))]。

投影片給 t=16 年、μ=10 年、n₁=220 千人，代入約 218.96 千人。原投影片最後數值代入那一行的分子漏寫一個 10；上方一般公式和此處數值使用的因子已補上。

第 75–78 頁 · Discounted claims

理賠發生在不同時間，要怎麼折現？

理賠以速率 λ 的 Poisson 過程發生；第 i 次發生時間 Sᵢ、金額 Cᵢ。金額彼此獨立同分配、平均 μ，且獨立於到達過程；折現率 α≥0。

D(t)= Σ_{i=1}^{N(t)} e^(−αSᵢ) Cᵢ。

先翻譯符號：每筆理賠金額 Cᵢ 要乘上它發生時間 Sᵢ 的折現係數，再把 t 之前的理賠加起來。N(t) 是隨機的，所以加總項數也隨機。

先假設已知總共發生 n 次

給定 N(t)=n，這 n 個到達時間的排序結果，分配和 n 個獨立 Uniform(0,t) 排序後相同。因為這裡將所有理賠項相加，排序不改變加總。我們可以用未排序的均勻時間 U 來算平均折現係數：

E[e^(−αU)] = (1/t)∫₀ᵗe^(−αu)du E[D(t) | N(t)=n] = n μ (1/t)∫₀ᵗe^(−αu)du。

為何可以拆開 E[Cᵢe^(−αU)]？因為理賠金額與到達時間獨立，所以等於 E[Cᵢ]E[e^(−αU)]。排序後的第 i 個到達時間 Sᵢ 本身並不是 Uniform(0,t)；這裡利用的是「總和對排序不敏感」。

最後把 n 換回隨機的 N(t)

E[D(t)] = E[E[D(t)|N(t)]] = E[N(t)] μ (1/t)∫₀ᵗe^(−αu)du = λμ ∫₀ᵗe^(−αu)du = (λμ/α)(1−e^(−αt))，α>0。

因 E[N(t)]=λt，剛好與均勻時間密度的 1/t 約掉。若 α=0 沒有折現，直接算 E[D(t)]=λμt；上式在 α→0 時也趨近它。

補充例：λ=2 次／年、μ=100 元、α=0.1／年、t=1 年。期望折現總額=200(1−e^(−0.1))/0.1≈190.33 元；不折現則平均 200 元。
第 79 頁 · Optimization

中間何時送一次貨，才能讓總等待最少？

貨物以速率 λ 到達。固定在 T 時把所有剩餘貨物送出；你可以額外選一個 t，在那時把系統中的貨都送出。目標是最小化所有貨物等待時間總和的期望。

先看第一段 [0,t]

若一件貨在 u 到達，會等到 t 才送出，所以等待 t−u。u 附近的平均到達數約 λdu；把每一小段的等待總和加起來：

第一段期望總等待 = ∫₀ᵗ λ(t−u)du = λt²/2。

同理，在 t 到 T 之間到達的貨，等到 T 時送出，期望總等待是 λ(T−t)²/2。兩段相加：

g(t) = λ[t²+(T−t)²]/2，0≤t≤T g′(t) = λ(2t−T)；g″(t)=2λ>0 g′(t)=0 ⇒ 最佳時間 t*=T/2。

因為二階導數正，曲線向上彎，這個駐點是最小值。直覺上：均勻的到達速率下，把兩個發貨間隔分成一樣長，能減少長時間累積的等待。

補充例：從早上 8 點到下午 2 點，共 T=6 小時，額外發貨時間選第 3 小時，也就是上午 11 點。若 λ=4 件／小時，最小期望總等待是 4(3²+3²)/2=36 件・小時。
第 80–87 頁 · Nonhomogeneous Poisson process

到達速率變動時，先求曲線下面積

以前的齊次 Poisson 假設 λ 固定；現在允許瞬時速率 λ(u) 隨時間變，例如早餐和午餐時段客流不同。過程仍有獨立增量，但一般不再有平穩增量：等長的兩段，發生次數的分配可能不同。

m(t) = ∫₀ᵗ λ(u)du（平均值函數） N(b)−N(a) ∼ Poisson(m(b)−m(a)) m(b)−m(a) = ∫ₐᵇ λ(u)du。

算題時三步驟：① 把題目時間換成模型時間；② 對該區間積分，得到平均次數 m；③ 代 Poisson(m) 的機率公式。

原題：熱狗攤 p.85–87

t=0 是早上 8 點，以小時為單位。店開 9 小時：8–11 點速率從 5 線性升至 20；11–13 點維持 20；13–17 點線性降至 12。

λ(t) = 5+5t，0≤t≤3 20，3<t≤5 20−2(t−5)，5<t≤9。

8:30 至 9:30 對應 0.5 到 1.5，兩個時間都落在第一段，所以：

m = ∫₀.₅¹.₅ (5+5t)dt = [5t+2.5t²]₀.₅¹.₅ = 10 E[人數]=10 P(沒客人)=e^(−10)≈0.0000454。

如果區間跨越上午 11 點，必須在 t=3 切開，分別積分各段再相加。題目描述的平均速率與獨立增量支持 Poisson 建模，但實務上仍是模型假設。

新版第 83–84 頁：篩選法為什麼有效？

設想原先有每小時 Λ 次的候選事件，想要的目標速率是 λ(u)，且所有觀察時間都滿足 0≤λ(u)≤Λ。時刻 u 每個候選事件以機率 λ(u)/Λ 獨立保留，否則刪除。

候選速率 × 保留機率 = Λ × [λ(u)/Λ] = λ(u) 拒絕機率 = 1−λ(u)/Λ。

例如候選速率 Λ=20／小時，在目標速率為 5／小時的時刻，每個候選事件以 5/20=1/4 的機率保留；在目標速率為 15／小時的時刻則保留 3/4。第 84 頁的 m(t)=∫₀ᵗλ(u)du 是把每小段平均次數加總的結果；固定 t 時 N(t) 是 Poisson 隨機變數，而整個 {N(t):t≥0} 才是隨機過程。

兩條變速流程合併與分流

兩條互相獨立的非齊次過程，速率分別 λ₁(t)、λ₂(t)，合併速率為兩者相加。時間 t 附近的一個到達來自第一條的比例為 λ₁(t)/[λ₁(t)+λ₂(t)]，總速率須大於 0。這是對小時間區間取極限的意思，因為「恰好在固定 t 發生」本身是機率為 0 的事件。

反過來，如果 λ(t)≤Λ，可先產生速率 Λ 的齊次 Poisson 事件，再以 λ(t)/Λ 的機率獨立保留時間 t 的事件；保留的過程就是期望速率 λ(t) 的非齊次 Poisson 過程。

第 88–93 頁 · Compound Poisson

每次來一群人：總人數怎麼算？

以前 N(t) 數的是「來了幾次」。如果每次來的是一個家庭，每個家庭的人數可能不同，我們想算的是所有家庭加起來有幾個人。

Z(t) = Σ_{i=1}^{N(t)} Yᵢ。

這裡 N(t) 是家庭數，Yᵢ 是第 i 戶人數，Z(t) 是總人數。若沒有家庭到達，N(t)=0，總和就是 0。假設 N(t)∼Poisson(λt)，各 Yᵢ 獨立同分配，也與 N(t) 獨立；設 μ=E[Y]、σ²=Var(Y)，二階動差有限。

期望：先固定家庭數

假如已經知道來了 n 戶，平均總人數就是 nμ。再把隨機的家庭數考慮進來：

E[Z(t) | N(t)=n] = nμ E[Z(t)] = E[E[Z(t)|N(t)]] = E[N(t)]μ = λtμ。

變異數：為什麼要多算一項？

總人數有兩個波動來源：第一，即使固定來了 n 戶，每戶人數還是會不同；第二，來了幾戶本身也會變。

Var(Z) = E[Var(Z|N)] + Var(E[Z|N]) = E[N]σ² + Var(N)μ² = λtσ² + λtμ² = λt E[Y²]。

第一項 E[N]σ² 是每戶大小造成的波動；第二項 Var(N)μ² 是戶數不固定造成的波動。最後用 σ²+μ²=E[Y²]。因此不能只寫 λtVar(Y)。

原題：家庭移入 p.92–93

家庭以每週 2 戶到達，觀察 5 週，所以平均家庭數 λt=10。每戶人數 Y 為 1、2、3、4 的機率依序是 1/6、1/3、1/3、1/6。

E[Y] = 1(1/6)+2(1/3)+3(1/3)+4(1/6) = 5/2 E[Y²] = 1²(1/6)+2²(1/3)+3²(1/3)+4²(1/6) = 43/6 E[Z(5)] = 10×5/2 = 25 人 Var(Z(5)) = 10×43/6 = 215/3 人²。

變異數的單位是人²。如果題目問標準差，還要開根號，約 8.47 人。

自我檢查：如果每戶永遠剛好 1 人，那 Y=1、Var(Y)=0；但家庭到達數仍然隨機，所以總人數的變異數不會是 0，而是 λt。這能看出第二項為什麼不可省略。

自己試試，點開看解答

練習 1：每小時 6 人，兩小時內每人獨立以 1/3 機率為 A。A 的平均與分配？

平均 6×2×(1/3)=4，所以 A∼Poisson(4)。A=0 的機率是 e^(−4)。

練習 2：λ=3／小時，所有人服務都固定 2 小時，系統從空開始。1 小時時還有多少人正在服務？

在 0 到 1 小時到達的人，到 1 小時時最多服務 1 小時，因此一定都還在。Y(1)=N(1)∼Poisson(3)，平均 3 人。公式中 Q(v)=1，對 v∈[0,1] 積分得到 3。

練習 3：λ(t)=2+t／小時，t 從 0 開始算，1 到 3 小時沒有到達的機率？

m=∫₁³(2+t)dt=[2t+t²/2]₁³=8，因此 P(0)=e^(−8)。

練習 4：1 小時來的車數 ∼ Poisson(2)，每車獨立帶 1 或 3 人，各半。總人數的期望和變異數？

E[Y]=2、E[Y²]=(1+9)/2=5，所以 E[總人數]=2×2=4 人，Var=2×5=10 人²。

練習 5：λ=4／小時、服務時間固定 1 小時，求 t=2 與 t+s=2.5 的服務人數共變異數。

Q(v)=1 當 v<1、其餘為 0。共變異數 4∫₀²Q(v+0.5)dv=4×0.5=2。共同顧客是 1.5 到 2 小時之間到達的人。
