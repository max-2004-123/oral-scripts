01 / Exponential distribution · pp.2–3

λ 是速率，不是平均等待時間

令 X 是從現在起「還要等多久」。寫成 X ∼ Exp(λ)，表示 X 服從速率參數 λ > 0的指數分配。λ 越大，事件越快發生，等待越短。

先用單位理解 · 補充例

平均每小時 2 次的速率，λ = 2／小時，平均等待是 1/2 小時，也就是 30 分鐘。若改用分鐘表示，速率是 2/60 = 1/30／分鐘，不能直接把「2」放進以分鐘計算的公式。

一個分配，三種問法

fX(x) = λe−λx，x ≥ 0FX(x) = P(X ≤ x) = 1 − e−λx，x ≥ 0SX(x) = P(X > x) = e−λx，x ≥ 0
  • 密度 f：描述機率集中在哪裡。P(x < X ≤ x + Δx) 在 Δx 很小時約為 f(x)Δx。
  • 累積機率 F：到 x 時已經發生的機率，等於密度從 0 到 x 的面積。
  • 存活函數 S：到 x 時仍未發生的機率。「超過」「還沒」「至少再等」通常先想 S。

當 x < 0，f(x) = F(x) = 0，而 S(x) = 1，因為等待時間不會是負的。連續分配在單點的機率是零，所以 P(X = x) = 0，這裡 > 與 ≥ 不影響機率。

展開：從密度積分得到 CDF
F(x) = ∫₀ˣ λe−λu du= [−e−λu]₀ˣ = 1 − e−λx

密度從 0 到無限大的積分是 1。區間機率用兩個累積機率相減：

P(a < X ≤ b) = F(b) − F(a) = e−λa − e−λb，0 ≤ a ≤ b。
常見錯誤：密度不是機率。

λ = 2 時 f(0) = 2，完全合法。只有曲線下面積才是機率；一個點的「高度」可以超過 1。

互動實驗 01

改變速率，看看等待怎麼縮短

時間單位：小時。圖上畫的是存活機率 S(t)，不是密度。虛線標出你選的時間。

試試把 λ 加倍：在同一個 t，存活機率變小；平均等待時間恰好減半。

02 / Moments & MGF · pp.2–3

平均等多久？波動有多大？

期望是長期平均，不代表每次都會等這麼久。指數分配的標準差剛好等於平均數，所以它的等待時間其實相當分散。

E[X] = 1/λE[X²] = 2/λ²Var(X) = 1/λ²，SD(X) = 1/λ

先把期望的積分補完整

使用分部積分 ∫u dv = uv − ∫v du。取 u = x、dv = λe−λxdx，則 du = dx、v = −e−λx：

E[X] = ∫₀∞ xλe−λx dx= [−xe−λx]₀∞ + ∫₀∞ e−λx dx= 0 + 1/λ

邊界為 0，是因為指數衰減比 x 的線性成長快。補充的快速記法：任何非負隨機變數都有 E[X] = ∫₀∞ P(X > x)dx；代入存活函數也得到 1/λ。

MGF 是把各階動差裝在一個函數裡

為了不跟等待時間 t 混淆，這裡把 MGF 的輸入改叫 u。它的定義是 MX(u) = E[euX]。

MX(u) = ∫₀∞ λe−(λ−u)x dx = λ/(λ − u)，u < λM′X(u) = λ/(λ − u)²M″X(u) = 2λ/(λ − u)³M′X(0) = E[X] = 1/λM″X(0) = E[X²] = 2/λ²

u < λ 讓指數仍然衰減，積分才有限。若 u ≥ λ，這個期望發散。別忘記二階動差還不是變異數，必須再減去平均數的平方：

Var(X) = E[X²] − (E[X])² = 2/λ² − 1/λ² = 1/λ²。
單位檢查 · 補充例

若平均 10 分鐘，λ = 0.1／分鐘。E[X] = 10 分鐘，Var(X) = 100 分鐘²，SD(X) = 10 分鐘。把變異數寫成「100 分鐘」會少一個平方。

03 / Discounted reward · pp.4–6

折現，竟然可以看成隨機停止

假設時間 x 的報酬速率是 R(x)，例如每分鐘賺多少元。總報酬要對時間積分。若越晚的收入折現越多，折現率為 α，現在價值是：

D = ∫₀∞ e−αxR(x) dx。

這裡 e−αx剛好長得像指數分配的存活機率。令 T ∼ Exp(α)，且 T 與報酬過程獨立。想像收入在 T 時突然停止，但停止前都不折現。兩者的期望值相同。

每天收入打折
權重 e−αx期望相同 ⇄收入不打折
但以機率 e−αx持續到 x

關鍵工具：指示變數

定義 I(x) = 1{T ≥ x}：如果 x 時還沒停止就等於 1，否則等於 0。因此「只積到 T」可以改寫成「積到無限大，但停止後全部乘 0」。

∫₀ᵀ R(x)dx = ∫₀∞ R(x)I(x)dxE[∫₀ᵀ R(x)dx] = ∫₀∞ E[R(x)I(x)]dx= ∫₀∞ E[R(x)]E[I(x)]dx= ∫₀∞ E[R(x)]P(T ≥ x)dx= ∫₀∞ e−αxE[R(x)]dx = E[D]
  1. 第二行把期望與積分交換。
  2. 第三行用獨立性，把乘積期望拆開。
  3. 第四行用「0–1 指示變數的期望＝事件機率」。
  4. 最後一行代入指數分配存活函數。
補充數字例

若固定每小時收入 100 元，α = 0.2／小時，折現總額是 100/0.2 = 500 元。若改成隨機停止，平均持續時間 E[T] = 5 小時，期望收入也是 100 × 5 = 500 元。

三個條件不能省略

這是期望相等，不是每條樣本路徑的報酬相等。交換積分與期望需非負報酬，或適當的絕對可積條件。Exp(α) 要求 α > 0；投影片先允許折現率 α = 0，但此時不能直接使用 Exp(0)，可將「永不停止」當成極限解讀，總報酬也可能無限大。

04 / Memorylessness · pp.7–9

等過了，不會讓剩下的時間變短

假設你已經等了 a 分鐘，而且事情還沒發生。無記憶性說：從現在重新計時，剩下的等待時間仍然服從原本的指數分配。

P(X > a + b | X > a) = P(X > b) = e−λb(X − a | X > a) ∼ Exp(λ)，a,b ≥ 0

注意括號裡有「已經撐過 a」這個條件。它不是說無條件的 X − a 也是指數分配。

證明只需要條件機率

P(X > a + b | X > a)= P(X > a + b) / P(X > a)= e−λ(a+b) / e−λa = e−λb

第一個等號成立，是因為 {X > a+b} 已經包含在 {X > a} 裡。a 被完全約掉了，這正是「不記得已經等了多久」。

原題 · p.8 · 銀行

銀行停留時間 X 的平均是 10 分鐘，λ = 0.1／分鐘。

  1. 剛進銀行，總共待超過 15 分鐘？
    P(X > 15) = e−1.5 ≈ 0.2231。
  2. 已待 10 分鐘還沒離開，總共待超過 15 分鐘？
    只需要「再待超過 5 分鐘」：P(X > 15 | X > 10) = e−0.5 ≈ 0.6065。

第二個機率比較大，因為你已知這個人不是很快離開的人；但從第 10 分鐘起的剩餘等待，仍與全新的等待同分配。

互動實驗 02

拖動「已經等多久」，答案真的不變

固定 λ = 0.1／分鐘。右邊顯示的條件機率只受 b 影響。

幾何分配是離散版本

若每次獨立試驗成功率為 p，X 表示第一次成功發生在第幾次，取值 1,2,…。前 a 次都失敗的機率為 (1−p)a，所以對非負整數 a,b：

P(X > a+b | X > a) = (1−p)a+b/(1−p)a = (1−p)b。

幾何分配數「試幾次」，指數分配量「等多久」。固定每 10 分鐘來一班的公車就不符合這種無記憶模型；等了 9 分鐘會有不同意義。

原題：第三個進郵局，最後離開的機率？

兩位櫃員正在服務 Jones 與 Brown，Smith 剛到且排在第一位。假設每次服務時間彼此獨立，且兩位櫃員都有相同速率 λ。

  1. 先等其中一人離開，Smith 才開始服務。
  2. 此刻還在服務的老顧客，其剩餘時間因無記憶性仍是 Exp(λ)。
  3. Smith 的新服務時間也獨立服從 Exp(λ)。
  4. 兩個同分配的連續時間互相比快慢，各有 1/2 的機率勝出。
答案是 1/2，不是 1/3。

Smith 開始服務時，已經有一個人離開了；他只需要跟剩下的那個人比。若兩位櫃員速率不同，就不能直接套對稱性。

05 / Deductible · pp.10–11

理賠不是「平均損失減自負額」

車禍損失 X 服從指數分配，平均 1000 元。自負額 400 元，保險只賠超過的部分，因此：

Y = (X − 400)+ = max(X − 400, 0)。

例如損失 250 元時賠 0；損失 1400 元時賠 1000。不能算 E[Y] = 1000 − 400 = 600，因為低於 400 的情況不會出現「負理賠」。

拆成有賠與沒賠兩種情況

令 I = 1{X > 400}，有理賠的機率 q = e−400/1000 = e−0.4。

條件Y 的情況條件期望條件變異數
I = 0Y = 000
I = 1超過 400 的部分仍是 Exp(0.001)10001000²

第二行不是重新假設，而是無記憶性：(X−400 | X>400) 跟 X 同分配。因此 E[Y | I] = 1000I、Var(Y | I) = 10⁶I。

E[Y] = E[E[Y | I]] = 1000q ≈ 670.32Var(Y) = E[Var(Y | I)] + Var(E[Y | I])= 10⁶q + 10⁶q(1−q) = 10⁶(2q−q²)SD(Y) = 1000√(2q−q²) ≈ 944.09

全變異數第一項是「有理賠時金額本身的波動」；第二項是「有賠與沒賠的平均金額不同」造成的波動。只算第一項會低估變異數。

另一種驗算：直接算二階動差

有賠時，E[Y² | I=1] = 2 × 1000²；沒賠時是 0。所以 E[Y²] = 2 × 10⁶q。再減 (1000q)²，就得到相同的變異數。

一般化：若 X ∼ Exp(λ)、自負額 d ≥ 0、q = e−λd，則 E[(X−d)⁺] = q/λ，Var((X−d)⁺) = (2q−q²)/λ²。

「每次事故」與「每次有理賠」不一樣。

題目問每次事故的平均支出，所以答案 670.32 包含零理賠。只看有理賠的事故，條件平均才是 1000。

06 / Inventory optimization · pp.12–14

訂多少，才能讓平均利潤最大？

下個月需求 X ∼ Exp(λ)。每單位售價 s、進貨成本 c，且 s > c > 0。訂購量用 q 表示（投影片用 t），避免誤認為時間。賣出的數量是 min(X,q)，不是 X，也不是 q。

Π(q) = s min(X,q) − cq。

假設剩貨沒有價值，缺貨也沒有額外罰款。這是一個需求量模型；此時 λ 的單位是「每單位商品」，不是每分鐘。

步驟一：先求平均賣出多少

恆等式 min(X,q) = X − (X−q)⁺，意思是需求扣掉沒滿足的部分，就等於實際銷量。上一節的自負額技巧又出現了：

E[(X−q)⁺] = P(X>q) E[X−q | X>q]= e−λq/λE[min(X,q)] = (1 − e−λq)/λ

步驟二：寫出平均利潤，再微分

g(q) = E[Π(q)] = (s/λ)(1 − e−λq) − cqg′(q) = se−λq − cg′(q*) = 0 ⇒ q* = (1/λ) ln(s/c)g″(q) = −sλe−λq < 0

二階導數小於 0，表示曲線是凹的，所以這個駐點確實是唯一最大值。不是微分等於零就一定最大。

經濟直覺：最後一單位值不值得買？

再多訂一點，只有需求超過目前庫存時才賣得掉。邊際期望收入是 sP(X>q) = se−λq，成本是 c。最適點正是兩者相等。

互動實驗 03 · 補充數字例

訂購量不一定等於平均需求

固定平均需求 100 單位（λ = 0.01）、每單位成本 c = 20 元。滑動售價與你選的訂購量；橘線標出最佳量。

延伸原題：剩貨可退，缺貨有罰款

每單位剩貨回收 r 元，0 ≤ r < c < s；每單位未滿足需求罰 p ≥ 0 元。先分清楚兩種正部：剩貨是 (q−X)⁺，缺貨是 (X−q)⁺。

Π(q) = s min(X,q) − cq + r(q−X)⁺ − p(X−q)⁺E[(q−X)⁺] = q − E[min(X,q)]g(q) = (s−r)/λ − (s+p−r)e−λq/λ − (c−r)qg′(q) = (s+p−r)e−λq − (c−r)q* = (1/λ) ln[(s+p−r)/(c−r)]

同樣有 g″(q) < 0。售價 s 或缺貨罰款 p 越高，少訂越吃虧，所以 q* 增加；回收價 r 越高，多訂的風險越小，q* 也增加。成本 c 增加則少訂。λ 增加代表平均需求 1/λ 下降，因此少訂。

檢查特例與邊界

令 r = p = 0，就回到 ln(s/c)/λ。若基本模型 s ≤ c，非負訂購量的最適解是 q = 0，不應接受負的訂購量。此處的公式將商品視為可連續分割；若只能訂整數，對凹利潤函數比較 q* 上下相鄰的可行整數即可。

補充例：λ=0.01、s=50、c=20、r=5、p=10，q*=100 ln(55/15)≈129.93。基本模型是 100 ln(50/20)≈91.63；可回收又怕缺貨，自然更願意多訂。

07 / Hyperexponential · pp.15–19

混合分配：先抽類型，再等它壞掉

一箱電池有不同類型。先隨機抽一顆，再看它的壽命。你只用一顆，不是把每種類型的壽命加起來。令 T 是抽到的類型，P(T=i)=pᵢ，Σpᵢ=1；給定 T=i，X 的速率為 λᵢ。

抽類型 T→以機率 pᵢ 選到 i→只用 Xᵢ ∼ Exp(λᵢ)

課本用獨立的 X₁,…,Xₙ 和獨立的選擇變數 T，寫 X = XT。求混合分配最直接的方法是對類型做條件化：

P(X>t) = Σᵢ pᵢP(X>t | T=i) = Σᵢ pᵢe−λᵢtfX(t) = Σᵢ pᵢλᵢe−λᵢt，t ≥ 0E[X] = Σᵢ pᵢE[X | T=i] = Σᵢ pᵢ/λᵢ
原題 · pp.17–19

80% 電池平均壽命 1 小時，20% 電池平均壽命 10 小時。因此速率分別是 1 與 0.1／小時。

P(X>5) = 0.8e−5 + 0.2e−0.5 ≈ 0.1267E[X] = 0.8×1 + 0.2×10 = 2.8 小時

不能先平均速率得到 0.82，再用 Exp(0.82)。倒數與加權平均不能交換，1/0.82 ≈ 1.22 也不是正確的 2.8。

補充理解：混合後通常不再無記憶

單一類型的電池沒有記憶，但「類型未知」的整箱電池一般沒有這個性質。若一顆電池已經活很久，你會更相信它來自長壽類型。用 Bayes 公式可量化這個資訊更新：

P(T=2 | X>5) = 0.2e−0.5 / (0.8e−5 + 0.2e−0.5) ≈ 0.9575。

長壽類型原先只有 20%，撐過 5 小時後卻約有 95.75% 的機率是它。所以混合的剩餘壽命分配會隨已活多久改變。只有所有有效類型速率相同等退化情況，才回到單一指數分配。

08 / Exponential races · pp.20–23, 26

同時開始：等最快的，要把速率加起來

讓 n 個互相獨立的指數時鐘一起跑，Xᵢ ∼ Exp(λᵢ)。令 M = min(X₁,…,Xₙ) 是第一個事件的時間；J 是第一個發生的編號。這裡有兩個不同問題：多久有第一個？哪一個先？

第一題：最小值的分配

M > t 表示「沒有任何一個在 t 前完成」，也就是全部 Xᵢ 都大於 t。獨立性允許機率相乘。

P(M>t) = P(X₁>t,…,Xₙ>t)= ∏ᵢ e−λᵢt = e−(Σᵢλᵢ)tM ∼ Exp(Λ)，Λ = Σᵢλᵢ，E[M] = 1/Λ

更多時鐘一起競賽，通常更快有人完成，所以加的是速率；不是把平均等待相加。

第二題：哪一個先？

若第 i 個在 t 附近先發生，它需要自己在 t 附近完成，而其他全部撐過 t。將 t 從 0 積到無限大：

P(J=i) = ∫₀∞ fᵢ(t) ∏ⱼ≠ᵢ P(Xⱼ>t) dt= ∫₀∞ λᵢe−Λtdt = λᵢ/Λ
原題數字 · pp.21–22

λ₁=2、λ₂=3，單位都是每小時。第一位先完成機率 2/5=0.4，第二位是 3/5=0.6。平均等到第一次完成的時間是 1/5 小時 = 12 分鐘。速率 3 的比較快，因此它比較可能先完成。

互動實驗 04

誰先完成？你要等多久？

此處顯示理論值。下節的總停留時間還要加上你自己的服務時間。

更厲害的性質：第一個時間與勝出者獨立

直覺上你可能覺得「很快就有人完成，一定比較像快櫃員」。但在這個獨立指數模型中，第一個時間 M 與勝出者 J 恰好獨立。證明看聯合密度的分解：

fM,J=i(t) = λᵢe−Λt= (λᵢ/Λ) × (Λe−Λt) = P(J=i) fM(t)

所以 E[M | J=i] = 1/Λ。已知第 1 位贏了，他的完成時間不再有原本 1/λ₁ 的平均；因為你只挑了他贏的那些情況。

p.26 的完整性質：M 甚至與整個名次排序獨立

給定 M>t，就是所有時鐘都還沒響。由獨立性與無記憶性，各個 Xᵢ−t 在此條件下仍互相獨立且服從原來的 Exp(λᵢ)。所有時間減掉同一個 t 不改變排序，因此對任何排列 i₁,…,iₙ：

P(Xᵢ₁ < ⋯ < Xᵢₙ | M>t) = P(Xᵢ₁ < ⋯ < Xᵢₙ)。

這對所有 t ≥ 0 都成立，故最小值與整個排序獨立。這不是說 X₁ 與 M 獨立，也不是說所有順序統計量彼此獨立。

使用前先找「獨立」兩個字。

若兩個設備會受同一個故障影響，不能直接把 P(X₁>t,X₂>t) 拆成乘積，最小值公式和速率比例也就不保證成立。

09 / Post office example · pp.24–27

在郵局待多久 = 排隊 + 自己辦事

你進郵局時兩位櫃員都忙，但前面沒人排隊。兩位速率分別 λ₁、λ₂，可以不同。假設各次服務互相獨立，且你由先空出的櫃員服務。

令 R₁、R₂ 為兩位現有顧客的剩餘服務時間；S 是你自己的服務時間；T 是你的總停留時間。因無記憶性，Rᵢ 仍是 Exp(λᵢ)。設 Λ = λ₁+λ₂。

等任一櫃員空出
W = min(R₁,R₂)＋你自己的服務
S＝總時間 T

解法 A：先拆時間，最不容易錯

E[W] = 1/ΛE[S] = P(J=1)E[S | J=1] + P(J=2)E[S | J=2]= (λ₁/Λ)(1/λ₁) + (λ₂/Λ)(1/λ₂) = 2/ΛE[T] = E[W] + E[S] = 3/(λ₁+λ₂)

快櫃員比較容易先空出，所以不是平均各有 1/2 機率。每一項都是「被分到該櫃員的機率 × 在那裡的平均服務時間」。期望相加本身不需要 W 與 S 獨立。

解法 B：先看被分到哪位櫃員

因上一節的 M 與勝出者獨立：

E[T | J=1] = 1/Λ + 1/λ₁E[T | J=2] = 1/Λ + 1/λ₂E[T] = (λ₁/Λ)(1/Λ+1/λ₁) + (λ₂/Λ)(1/Λ+1/λ₂)= 1/Λ + 2/Λ = 3/Λ
沿用 λ₁=2、λ₂=3 · 補充計算

排隊平均 12 分鐘；自己的服務平均 (0.4×30)+(0.6×20)=24 分鐘；總共 36 分鐘。總停留不是 12 分鐘，也不是 12+30+20 分鐘，因為你只會由其中一位服務。

這不是所有兩櫃員排隊問題的通用答案。

3/(λ₁+λ₂) 用到「到達時兩位都忙、無其他人等待、指數且獨立、你去先空出的櫃員」這些條件。換成前面還排五個人，模型就不同。

10 / Hypoexponential & convolution · pp.28–32

依序完成：把時間加起來，不能把速率相加

這次你先用完第一顆電池，再換第二顆；總壽命 S = X₁+X₂。兩者獨立，速率不同。這種「一段接一段」的總和稱為 hypoexponential 分配。

第一段 X₁→第二段 X₂→總時間 S = X₁+X₂

卷積的意思：枚舉所有湊成 t 的方法

總時間要在 t 附近，第一段可能花 u，第二段就要花 t−u。u 不可能小於 0，也不可能大於 t，所以積分範圍是 0 到 t。

fS(t) = ∫₀ᵗ f₁(u)f₂(t−u) du= λ₁λ₂e−λ₂t ∫₀ᵗ e−(λ₁−λ₂)udu= [λ₁λ₂/(λ₁−λ₂)] (e−λ₂t − e−λ₁t)，t ≥ 0

這個公式要求 λ₁ ≠ λ₂。對 t < 0，密度為 0。看起來是兩個指數項相減，但整體仍是非負密度；例如 λ₁>λ₂ 時分母為正，括號也非負。

原題 · pp.30–32 · 兩顆電池接力

第一顆平均 1 小時，第二顆平均 2 小時。兩者獨立；切換無延遲，備用電池在等待時不老化。因此 λ₁=1、λ₂=0.5，而不是 1 和 2。

fS(t) = e−0.5t − e−t，t ≥ 0P(S>t) = ∫ₜ∞ fS(u)du = 2e−0.5t − e−tP(S>3) = 2e−1.5 − e−3 ≈ 0.3965E[S] = 1/1 + 1/0.5 = 3 小時

注意存活函數第一項的係數 2，是對 e−0.5t積分產生的。如果直接拿密度在 t=3 的值當作機率，就會算錯。

n 個不同速率的階段

對互相獨立、速率兩兩不同的 X₁,…,Xₙ，令：

Aᵢ = ∏ⱼ≠ᵢ [λⱼ/(λⱼ−λᵢ)]fS(t) = Σᵢ Aᵢλᵢe−λᵢtP(S>t) = Σᵢ Aᵢe−λᵢt，t ≥ 0E[S] = Σᵢ 1/λᵢ

Aᵢ 可能是負的，因此這不是混合分配的類型機率 pᵢ。不要看到「指數項的加總」就當成 hyperexponential。

怎麼理解一般公式的來源？

獨立和的 Laplace 轉換為 E[e−uS] = ∏ᵢ λᵢ/(λᵢ+u)。當速率互不相同，可以做部分分式分解，寫成 Σᵢ Aᵢλᵢ/(λᵢ+u)。每一項對應回指數密度，便得到投影片的結果。實際考題若只問平均，直接用期望線性性，不必先求密度。

速率相同不能硬套分母 λ₁−λ₂。

如果 λ₁=λ₂=λ，卷積內的指數因子變成 1，積分直接等於 t，得到 fS(t)=λ²te−λt。這就是下一節的 Gamma(2,λ)。

11 / Gamma & Erlang · pp.33–34

等第 n 次發生：Gamma 分配

假設每一段間隔 X₁,X₂,… 都互相獨立且同分配為 Exp(λ)。令 Sₙ = X₁+⋯+Xₙ，是從 0 開始等到第 n 次事件的時間。

Sₙ ∼ Gamma(n, λ)fSₙ(t) = λⁿtn−1e−λt/(n−1)!，t > 0= λe−λt(λt)n−1/Γ(n)，Γ(n)=(n−1)!

這裡 n 是形狀參數、λ 是速率參數。當形狀 n 為正整數，通常也叫 Erlang 分配。另一些教材使用尺度 θ = 1/λ；遇到 Gamma(n,θ) 時先確認定義，不要只看符號。

E[Sₙ] = n/λ，Var(Sₙ) = n/λ²。

期望把每段的 1/λ 相加；變異數相加則用到獨立性。n=1 時恰好退回指數分配。

p.34 的跳步：等待時間怎麼變成事件數？

令 N(t) 表示時間 t 以前發生了幾次事件。以獨立同分配的 Exp(λ) 間隔所構成的到達模型，對應速率 λ 的 Poisson 過程，N(t) ∼ Poisson(λt)。這裡只用它的計數機率：

P(N(t)=j) = e−λt(λt)ʲ/j!，j=0,1,2,…。

「第 n 次在 t 以前到達」與「到 t 時已經至少發生 n 次」是同一個事件：

{Sₙ ≤ t} ⇔ {N(t) ≥ n}FSₙ(t) = 1 − Σⱼ₌₀ⁿ⁻¹ e−λt(λt)ʲ/j!P(Sₙ>t) = Σⱼ₌₀ⁿ⁻¹ e−λt(λt)ʲ/j!

尤其注意上下界：尚未等到第 n 次，就只有 0 到 n−1 次；不是 0 到 n 次。N(t) 是離散的次數，Sₙ 是連續的時間，兩者不能混成同一個隨機變數。

把投影片的「⋯」補完：微分後為什麼只剩一項？

令 z=λt。對有限和形式的 CDF 微分，比無限和更清楚：

F(t) = 1 − e−λt Σⱼ₌₀ⁿ⁻¹ (λt)ʲ/j!F′(t) = λe−λt Σⱼ₌₀ⁿ⁻¹ (λt)ʲ/j!　− λe−λt Σⱼ₌₁ⁿ⁻¹ (λt)j−1/(j−1)!

第二個和令 k=j−1，就從 k=0 加到 n−2。第一個和從 0 加到 n−1，前 n−1 項全部相消，只留下最高次那項：

F′(t) = λe−λt(λt)n−1/(n−1)!。

n=1 時第二個和是空和，視為 0，同樣成立。

不用先學 Poisson，也能證明 Gamma：卷積歸納

n=1 就是指數密度。假設 n 段的密度已成立，加入獨立的第 n+1 段：

fSₙ₊₁(t) = ∫₀ᵗ [λⁿun−1e−λu/(n−1)!] λe−λ(t−u)du= λn+1e−λt/(n−1)! × ∫₀ᵗ un−1du= λn+1tⁿe−λt/n!

這就是 Gamma(n+1,λ) 的密度，因此用歸納法得到所有正整數 n。這個證法也說明：每一段速率相同，指數項才會合併成 e−λt。

互動實驗 05 · 補充數字例

等一次，與等三次，有什麼不同？

固定 λ=2／小時。綠色是 Gamma(n,2) 密度；橘色虛線是單次等待 Exp(2) 密度，方便比較。密度高度不是機率。

Gamma(n,2)Exp(2) 基準
補充例 · 第三次事件在 1 小時內？

λ=2／小時、n=3。只需要算「至少 3 次」的補事件：

P(S₃≤1) = 1 − P(N(1)≤2)= 1 − e−2(1 + 2 + 2²/2!)= 1 − 5e−2 ≈ 0.3233

平均等到第三次需要 3/2=1.5 小時，但在 1 小時內等到的機率仍有約 32.33%。平均時間不是硬性截止線。

快速自測：混合、最小值、總和

1.兩個獨立設備同時運轉，壽命速率為 2、3／小時。等到第一台故障的平均時間？

2.一顆隨機抽到的電池，50% 來自平均 1 小時的類型，50% 來自平均 3 小時的類型。平均壽命？

3.三段獨立 Exp(2) 等待時間相加，分配與平均為何？

完整練習：自己算一次

練習 1｜平均等待 8 分鐘，已等 5 分鐘，總等待超過 12 分鐘的機率？

λ=1/8。剩下的門檻是 12−5=7 分鐘，所以 P(X>12 | X>5)=e−7/8≈0.4169。不是 e−12/8，也不是 e−5/8。

練習 2｜損失平均 2000 元，自負額 500 元，平均每次事故賠多少？

λ=1/2000，理賠機率 q=e−0.25。有理賠時的平均超額仍為 2000，故 E[Y]=2000e−0.25≈1557.60 元。未理賠時賠 0 已包含在內。

練習 3｜需求平均 50、售價 30、成本 10，無殘值與缺貨罰款，最佳訂購量？

λ=1/50。q*=50 ln(30/10)=50 ln3≈54.93 單位。平均需求 50 不一定等於最佳庫存；此題缺貨損失相對高，所以多訂一些。

練習 4｜兩個忙碌櫃員的平均服務時間為 10、20 分鐘，無人排隊，你平均待多久？

λ₁=0.1、λ₂=0.05／分鐘。排隊平均 1/0.15=6.67 分鐘；自己服務平均 (2/3)×10+(1/3)×20=13.33 分鐘。總共 20 分鐘，也就是 3/0.15。

練習 5｜兩顆獨立電池各平均 2 小時，依序用完，總壽命超過 3 小時的機率？

相同速率 λ=0.5，總時間 S∼Gamma(2,0.5)。P(S>3)=e−1.5(1+1.5)≈0.5578。不能用不同速率公式直接除以 0。

練習 6｜速率為 1、2、3 的三個獨立時鐘，第一個勝出的機率與平均最短等待？

Λ=6。各自勝出機率是 1/6、2/6、3/6，合計 1；平均最短等待 1/6 時間單位。已知第 3 個勝出時，最短等待的條件平均仍為 1/6，因為 M 與勝出編號獨立。

考前，用自己的話講出這六句

  1. 速率 λ 越大，平均等待 1/λ 越小。
  2. 無記憶性是在「已經等到現在還沒發生」的條件下，剩餘時間重新開始。
  3. 混合是選一種；總和是每一段都經歷；最小值是任何一個完成就停止。
  4. 獨立指數競賽中，最小值速率相加，勝出機率按速率比例分配。
  5. 期望總和可直接相加；要求總和的密度，才需要卷積。
  6. 等到第 n 次是 Gamma；固定時間內數發生幾次是 Poisson。
